# Первый рейс

Кликабельный веб-прототип беспилотного такси для человека, который едет без водителя впервые.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

## Сценарий демо

`Доверие до заказа → заказ → ожидание → опознать машину → открыть дверь → посадка → поездка → завершение`.

Дополнительные ветки для демонстрации: задержка или отсутствие машины, отсутствие сети, объяснения манёвров, изменение планов, ситуации в салоне и три уровня поддержки — голосовой помощник, оператор и сотрудник по звонку.
